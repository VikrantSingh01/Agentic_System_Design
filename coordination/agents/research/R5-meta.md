# R5: Meta

## Mission

Research Meta's public work on open models, agent-relevant research, inference, fine-tuning decisions, deployment efficiency, and safety.

## Research questions

- What changes when a team self-hosts an open model rather than calling a managed API?
- Which inference, quantization, routing, and capacity considerations matter at production scale?
- When do fine-tuning or distillation improve an agent system compared with prompt, context, or tool changes?
- Which safety and license constraints need explicit system-design treatment?
