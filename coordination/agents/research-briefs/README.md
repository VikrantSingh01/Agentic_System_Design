# Stage 1 Research Briefs

This directory contains the short mission and coordination brief for each Stage 1 research agent. Run R1-R9 in parallel after Stage 0 passes. Each agent writes one completed evidence dossier under `research/dossiers/` and must not edit the shared source ledger, chapters, module indexes, contracts, or another dossier.

The briefs define assignments; they are not copies of the completed dossiers. If a mission changes, update its brief before revising the corresponding dossier.

## Required report

Every dossier must contain:

1. Scope and research questions
2. Durable findings
3. Evolving or contested findings
4. Production implications
5. Beginner misconceptions to address
6. Candidate primary sources
7. Claims requiring a release-time freshness check
8. Recommended chapter placements
9. Discrepancies or unresolved questions

Candidate sources must include publisher, title, URL, publication or update date, access date, supported claim, proposed chapter, and freshness class. The Source Editor alone accepts candidates into `research/source-ledger.csv` at J1.

## Shared constraints

- Use public, attributable evidence only.
- Prefer official papers, system cards, standards, documentation, engineering posts, and source repositories.
- Distinguish documented facts from interpretation.
- Do not infer private company architecture.
- Do not treat benchmark results or product announcements as general proof.
- Date all product, API, model, pricing, regulation, and protocol claims.
- Do not expose or require private chain-of-thought.
